# Clase 06 — M6: Multi-idioma (es / en / ca)

**Archivo destino: `src/components/language_selector.rs` + `i18n/*.ftl`.**

## Objetivo

Todo el texto del sitio en español, inglés y catalán, con un selector en el Header.
Buenas noticias: tus traducciones viejas (`i18n/es.ftl`, `en.ftl`, `ca.ftl`) siguen
en el proyecto y la librería `dioxus-i18n` ya está en `Cargo.toml`.

## Conceptos nuevos

### 1. Los archivos `.ftl` (Fluent)

Fluent es el formato de traducción de Mozilla. Cada línea es una clave:

```ftl
# i18n/es.ftl
hero-title = MitDevcat
hero-subtitle = Portafolio de proyectos
about-title = Sobre mí
```

### 2. Inicialización (una vez, en `App`)

```rust
use dioxus_i18n::prelude::*;
use unic_langid::langid;

use_init_i18n(|| {
    I18nConfig::new(langid!("es-ES"))
        .with_locale((langid!("es-ES"), include_str!("../i18n/es.ftl")))
        .with_locale((langid!("en-US"), include_str!("../i18n/en.ftl")))
        .with_locale((langid!("ca-ES"), include_str!("../i18n/ca.ftl")))
        .with_fallback(langid!("en-US"))
});
```

`include_str!` incrusta el archivo de texto en el binario: cero requests de red.

### 3. Traducir: la macro `t!`

```rust
h1 { t!("hero-title") }
p { t!("hero-subtitle") }
```

### 4. Cambiar de idioma

```rust
i18n.set_language(langid!("es-ES"));
```

`i18n` se obtiene con `use_i18n()`. Todo componente que usa `t!` se re-renderiza
solo cuando cambia el idioma: eso es lo hermoso del approach reactivo.

## Paso a paso

1. Inicializá i18n en `App` (arriba, antes del rsx).
2. Elegí 3-5 claves para empezar (títulos del Hero, About, Projects, Contact) y
   agregalas a los tres `.ftl`. Los archivos viejos tienen claves que podés reutilizar.
3. Reemplazá los textos fijos de Hero y secciones por `t!("clave")`.
4. Escribí `language_selector.rs`:

```rust
#[component]
pub fn LanguageSelector() -> Element {
    let mut i18n = use_i18n();

    rsx! {
        div { class: "language-selector",
            button { onclick: move |_| i18n.set_language(langid!("es-ES")), "ES" }
            button { onclick: move |_| i18n.set_language(langid!("en-US")), "EN" }
            button { onclick: move |_| i18n.set_language(langid!("ca-ES")), "CA" }
        }
    }
}
```

5. Montalo en el `Header` y marcá visualmente el idioma activo
   (pista: compará `i18n.language()` con cada `langid!`).
